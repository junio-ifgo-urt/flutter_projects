# Projetos Flutter

Repositório destinado ao armazenamento e versionamento dos meus projetos desenvolvidos com **Flutter** e **Dart**.

O objetivo é manter meus projetos disponíveis no GitHub para facilitar o desenvolvimento em diferentes máquinas e manter um histórico das alterações realizadas.

## 💻 Como utilizar

### 1. Clonar o repositório

```bash
git clone https://github.com/SEU-USUARIO/SEU-REPOSITORIO.git
```

### 2. Entrar no diretório

```bash
cd SEU-REPOSITORIO
```

### 3. Escolher um projeto

Por exemplo:

```bash
cd projeto-01
```

### 4. Instalar as dependências

```bash
flutter pub get
```

### 5. Executar o projeto

```bash
flutter run
```

## 🔄 Atualizando o repositório

Antes de começar a trabalhar em outra máquina, atualize o código:

```bash
git pull
```

Depois de realizar alterações:

```bash
git add .
git commit -m "Descrição das alterações"
git push
```

## ⚠️ Observações

Arquivos e diretórios gerados automaticamente pelo Flutter, como `.dart_tool/`, `build/` e outros arquivos temporários, não devem ser versionados.

O arquivo `.gitignore` do repositório contém as regras para impedir que esses arquivos sejam enviados ao GitHub.
